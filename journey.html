Here is my learning journey from June to March, including the challenges I faced along the way!

June

Explored how websites exist online and how URLs guide users to pages.

Challenge: Understanding the difference between a URL, domain, and server.

July

Practiced using web browsers and search engines to find resources and information online.

Challenge: Learning to search efficiently and identify reliable sources was tricky.

August

Learned HTML structure and linking pages together for smooth navigation.

Challenge: Remembering all the tags and their proper usage.

September

Practiced organizing data in HTML tables for clarity and accessibility.

Challenge: Aligning cells and nesting tables without breaking layout.

October

Created login forms and collected user input securely.

Challenge: Learning input types and validations.

November

Planned full website layouts for functionality and design.

Challenge: Making layouts look good on desktop and mobile.

December

Integrated multimedia like images, videos, and audio.

Challenge: Making multimedia responsive on all screens.

January

Mastered advanced form elements like checkboxes, radio buttons, and validations.

Challenge: Ensuring user-friendly functionality.

February

Learned CSS basics for colors, fonts, spacing, and backgrounds.

Challenge: Choosing colors and spacing that look harmonious.

March

Experimented with typography and tropical color schemes to make websites vibrant and unique.

Challenge: Balancing tropical colors and readability was tricky.
