Here is my learning journey from June to March, with reflections and experiences each month.

June – URL / World Wide Web

This month I explored how the internet works and how URLs help us access websites easily.

Challenge: Remembering the difference between domain names and IP addresses.

August – HTML Tags & Links

I learned to structure content using HTML tags and link pages together.

Challenge: Choosing the right tags for headings, paragraphs, and lists was tricky at first.

September – HTML Tables

This month was about organizing content into tables to display information clearly.

Challenge: Aligning columns and merging cells required precision.

October – Login Box & Input Types

I practiced creating input fields and login boxes to collect user information safely.

Challenge: Picking the correct input type for different fields needed attention.

November – Website Planning

I learned to sketch website layouts and plan the flow of information before coding.

Challenge: Visualizing the full website in advance was challenging but rewarding.

December – Multimedia

This month I added images, audio, and videos to make the website interactive.

Challenge: Placing media correctly without breaking the layout took practice.

January – Form Elements

I learned to create functional forms with buttons, checkboxes, and radio inputs.

Challenge: Arranging multiple elements neatly was sometimes tricky.

February – CSS Basics

I styled webpages using CSS to adjust colors, spacing, and layout for a cleaner design.

Challenge: Learning how CSS rules cascade and interact took patience.

March – CSS Font & Color

This month I experimented with fonts and color combinations to make the website readable and cute.

Challenge: Selecting colors that look good together was sometimes difficult.
